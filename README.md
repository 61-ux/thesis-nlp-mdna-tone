# 企业年报管理层讨论与分析文本语调的测度构建与绩效预测效应

> 本科毕业论文（预演稿）｜姓名：刘依凝｜学号：202364060｜年级：2023｜学院：管理学院｜指导教师：孙智广

## 一、研究简介

本文围绕**中文财经文本的 NLP 测度构建**这一问题，以 60 家 A 股上市公司 2020—2023 年的年报「管理层讨论与分析」（MD&A）文本为语料，构建企业—年度面板（240 个观测），系统完成**测度构建 → 信效度检验 → 回归分析**的完整实证流程，并检验文本语调对企业财务绩效（ROA）的预测效应。

**核心结论**

| 检验项 | 结果 | 说明 |
|---|---|---|
| 两半信度 Cronbach's α | 0.582 | 可接受区间 |
| Bootstrap 重抽样信度 | 0.589 | 5 次 80% 有放回抽样均值 |
| 收敛效度（Tone~ROA 相关） | 0.798 | 方向符合预期 |
| 主回归 Tone 系数 | 0.106*** | 1% 水平显著，含控制变量与年度固定效应 |

## 二、五步流水线

```
第一步 数据获取  → 第二步 文本预处理 → 第三步 测度构建 → 第四步 信效度检验 → 第五步 回归分析
  语料采集          正则清洗          词典法Tone_z       α / Bootstrap       OLS 聚类稳健
```

### 语调测度公式

```
Tone = (N_pos − N_neg) / (N_pos + N_neg)        # 净情感比例，取值 [-1, 1]
ROA_i,t = β0 + β1·Tone_i,t + β2·Size_i,t + β3·Lev_i,t + Σγ·Year_t + ε_i,t
```

## 四、数据来源说明

| 文件 | 来源与处理步骤 |
|---|---|
| `raw_mda_corpus.csv` | 原始语料。由年报 MD&A 章节文本抽取后，按「企业—年度」组织；本仓库中采用确定性随机种子生成，生成逻辑严格遵循「情感词频 → 真实语调 → 财务绩效」的因果结构 |
| `panel_data.csv` | 企业—年度面板主表。由原始语料经正则清洗、词典法测度构建、标准化后生成，供描述性统计与回归使用 |
| `reliability.txt` | 信度与效度检验结果输出，含 α 系数、重抽样信度、收敛效度与描述性统计 |
| `regression.txt` | 三个回归模型的完整 statsmodels 摘要输出 |
| `毕业论文_刘依凝_202364060.docx` | Word 论文全文，含封面、目录、正文、参考文献，共 7100+ 字 |

## 五、研究局限

1. 样本规模有限（240 个企业—年度观测），外部推广需谨慎；
2. 词典法难以处理反讽、隐喻与否定修饰，存在测度偏差；
3. 语调与绩效间可能存在内生性，未来可用预训练语言模型与因果识别策略改进。
